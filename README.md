# Hi, I'm Nicole 👋

Tools and experiments for everyday life with AI agents.

和 AI 一起读书、听歌，也做一些日常会用到的小工具。

### 📖 [Reading Cottage · 共读小屋](https://github.com/1nwooozip/reading-cottage)

A local EPUB reader for reading with AI agents. Share annotations and replies, keep reading notes, and compare parallel editions through a browser interface and MCP tools.

在书页旁和 agent 留批注、接着聊；支持中英界面、跨章笔记和双语对照。

### 🎬 [Not The Martian Again](https://1nwooozip.github.io/not-the-martian-again/)

An AI product case study: helping an agent use viewing history when choosing what to watch. From a manual movie list to MCP queries, with the iterations and remaining limitations along the way.

“今晚看什么？”从观影清单到 agent 可查询的记录，写下推荐与检索过程中的尝试。

[Read the case / 阅读案例](https://1nwooozip.github.io/not-the-martian-again/) · [Repository / 仓库](https://github.com/1nwooozip/not-the-martian-again)

### 🎵 [Netease Music MCP · 网易云音乐](https://github.com/1nwooozip/netease-music-mcp)

Let an agent search for songs and control the NeteaseMusic desktop app on macOS.

让 agent 在 macOS 网易云音乐里点歌、暂停、切歌和查看当前播放。
